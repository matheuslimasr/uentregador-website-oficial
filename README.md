# U Entregador

Plataforma de logística sob demanda conectando clientes, empresas e entregadores parceiros no estado de São Paulo.

## Desenvolvimento

Para rodar localmente, você precisa do Node.js ou Bun instalado.

```sh
# Instalar dependências
bun install # ou npm install

# Iniciar servidor de desenvolvimento
bun run dev # ou npm run dev

# Rodar testes
bun run test # ou npm test

# Build de produção
bun run build # ou npm run build
```
